🚀 WAT 101: WebAssembly Text Format

Step 1: What is WAT? 🤔

▶

WAT (WebAssembly Text Format) is the human-readable text representation of WebAssembly bytecode. Think of it as Assembly language for the web!

💡 Why learn WAT?
  • Understand how WebAssembly works under the hood
  • Debug and optimize WASM modules
  • Write high-performance web applications
  • Bridge the gap between high-level languages and machine code

Step 2: Your First Function 🔧

▶

Functions in WAT are defined with (func). Let's create a simple function that adds two numbers:

(module (func $add (param $a i32) (param $b i32) (result i32) local.get $a local.get $b i32.add ) (export "add" (func $add)) )

Breaking it down:

  • $add - Function name (optional)
  • (param $a i32) - Parameter named $a of type i32 (32-bit integer)
  • (result i32) - Function returns an i32
  • local.get $a - Push parameter $a onto the stack
  • i32.add - Pop two values, add them, push result
  • (export "add" (func $add)) - Make function available to JavaScript
🥞 Stack-Based Architecture:
WebAssembly uses a stack-based virtual machine. Operations push and pop values from an invisible stack.

Step 3: Data Types 📊

▶

WebAssembly has four basic data types:

  • i32 - 32-bit integer
  • i64 - 64-bit integer
  • f32 - 32-bit floating point
  • f64 - 64-bit floating point

Example: Working with different types

(module ;; Integer addition (func $add_i32 (param i32 i32) (result i32) local.get 0 local.get 1 i32.add ) ;; Float multiplication (func $multiply_f32 (param f32 f32) (result f32) local.get 0 local.get 1 f32.mul ) (export "add_i32" (func $add_i32)) (export "multiply_f32" (func $multiply_f32)) )
⚠️ Note: Parameters can be accessed by index (0, 1, 2...) or by name ($a, $b, $c...)

Step 4: Local Variables 📝

▶

Functions can have local variables in addition to parameters:

(module (func $calculate (param $a i32) (param $b i32) (result i32) (local $temp i32) (local $result i32) ;; temp = a + b local.get $a local.get $b i32.add local.set $temp ;; result = temp * 2 local.get $temp i32.const 2 i32.mul local.set $result ;; return result local.get $result ) (export "calculate" (func $calculate)) )

New concepts:

  • (local $temp i32) - Declare a local variable
  • local.set $temp - Store top of stack into variable
  • i32.const 2 - Push constant 2 onto stack

Step 5: Control Flow 🔄

▶

WAT supports control flow with blocks, loops, and conditional branches:

If-Else Example:

(module (func $max (param $a i32) (param $b i32) (result i32) local.get $a local.get $b local.get $a local.get $b i32.gt_s ;; greater than signed (if (result i32) (then local.get $a) (else local.get $b) ) ) (export "max" (func $max)) )

Loop Example:

(module (func $factorial (param $n i32) (result i32) (local $result i32) i32.const 1 local.set $result (block $exit (loop $loop local.get $n i32.const 1 i32.le_s ;; less than or equal br_if $exit local.get $result local.get $n i32.mul local.set $result local.get $n i32.const 1 i32.sub local.set $n br $loop ) ) local.get $result ) (export "factorial" (func $factorial)) )

Step 6: Memory Management 🧠

▶

WebAssembly modules can have linear memory for storing data:

(module (memory $mem 1) ;; 1 page = 64KB (export "memory" (memory $mem)) (func $store_and_load (param $offset i32) (param $value i32) (result i32) ;; Store value at memory offset local.get $offset local.get $value i32.store ;; Load value from memory offset local.get $offset i32.load ) (export "store_and_load" (func $store_and_load)) )

Memory operations:

  • (memory $mem 1) - Declare 1 page (64KB) of memory
  • i32.store - Store i32 value at address
  • i32.load - Load i32 value from address

Step 7: Function Tables 📋

▶

Function tables enable indirect function calls - like function pointers in C!

(module (table $functions 3 funcref) (func $add (param i32 i32) (result i32) local.get 0 local.get 1 i32.add ) (func $multiply (param i32 i32) (result i32) local.get 0 local.get 1 i32.mul ) (func $subtract (param i32 i32) (result i32) local.get 0 local.get 1 i32.sub ) (elem (i32.const 0) $add $multiply $subtract) (func $call_function (param $index i32) (param $a i32) (param $b i32) (result i32) local.get $a local.get $b local.get $index call_indirect (param i32 i32) (result i32) ) (export "call_function" (func $call_function)) )

Step 8: Importing from JavaScript 🔗

▶

WAT modules can import functions from JavaScript:

Step 9: Advanced WAT Features 🚀

▶

Multiple Return Values

(module (func $divmod (param $a i32) (param $b i32) (result i32 i32) local.get $a local.get $b i32.div_s ;; quotient local.get $a local.get $b i32.rem_s ;; remainder ) (export "divmod" (func $divmod)) )

Global Variables

(module (global $counter (mut i32) (i32.const 0)) (func $increment (export "increment") (result i32) global.get $counter i32.const 1 i32.add global.set $counter global.get $counter ) (func $get_counter (export "get_counter") (result i32) global.get $counter ) )
