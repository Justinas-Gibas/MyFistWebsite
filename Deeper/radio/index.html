How It Works

Either create a new room or join an existing one using a room ID.

Share Your Room

Communicate

The first person to join becomes the broadcaster. Others can listen and request broadcasting access.

Note: This application uses peer-to-peer WebRTC technology. Your voice data is transmitted directly between browsers without a central server. This application works best on modern browsers and devices.
