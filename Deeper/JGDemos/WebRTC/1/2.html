How It Works

Host Creates Offer

The host enables their microphone and generates an offer link.

Listener Processes Offer

The listener pastes the offer link and generates an answer link.

Host Completes Connection

The host pastes the answer link to establish the voice connection.

Note: This uses peer-to-peer WebRTC. No server needed - data goes directly between browsers!
