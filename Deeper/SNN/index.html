Welcome to SNN Playground

🎯 Goal To create an interactive, visual, and customizable simulation of spiking neural networks (SNNs) — inspired by the biology of real neurons — where individual neurons (or clusters) can be copied, tweaked, or interconnected in creative ways. The system should allow for: Copying neuron states ("neuron cloning") Running time-based neuron activity Observing learning behaviors Testing with toy inputs (like pixel sensors, sound spikes, etc.) This will serve as a relaxing and exploratory tool for personal learning, experimentation, and philosophical reflection on synthetic intelligence. 🧪 Inspiration Traditional neural networks are static function approximators. Spiking networks introduce time, stochasticity, and neuron individuality. Let’s simulate intelligence more like biology: spike-by-spike. 🔧 Technical Concepts Spiking Neurons (e.g., Leaky Integrate-and-Fire or Izhikevich models) Neurons accumulate potential over time. When a threshold is passed, they fire (“spike”). Spikes propagate through the network. Event-based Simulation Neurons react to discrete events rather than continuous data. Simulation ticks or a continuous time loop. Neuron Copy/Clone Ability to duplicate a single neuron's internal state (voltage, refractory time, connections). Enables "reproduction" or speculative branching of neuron types. Plasticity / Learning Rules Explore basic STDP (Spike-Timing Dependent Plasticity). Optional Hebbian learning or reinforcement modulation. Visual Playground UI Neurons are dots/circles. Spikes are lines or pulses. Time scrolls like a music sequencer or brainwave scanner.

Project Details

🖥️ Implementation Sketch Component Description Frontend Web app (React or Canvas/WebGL) or desktop (Tauri/Rust or Electron) Backend Rust/WASM or Python (for fast simulation of many neurons) Core Library Use or extend libraries like Brian2 (Python) or write your own minimal SNN engine Features Add / delete neurons, visualize spike trains, pause / resume simulation, edit synapses in real-time 🧰 Stretch Goals Import sounds or images as input spikes. Let users paint spikes or time patterns. Evolution: neurons adapt, mutate, or die. Add GPT-based agent commentary to narrate brain behavior. 💡 Vision This is not just an AI experiment. It’s a sandbox for exploring intelligence itself — one spike at a time. Let’s make a world where neurons are not numbers, but characters.
