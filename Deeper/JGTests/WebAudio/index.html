Handbook

Cheatsheet
  • Graph: source → filter → gain → sends → master → compressor → destination
  • ADSR: use AudioParam ramps on Gain / Filter cutoff.
  • Scheduler: schedule against audioCtx.currentTime with a small lookahead (0.1s).
  • FX Sends: split dry into parallel chains with GainNode mixers.
  • IR Reverb: load impulse response (WAV) into ConvolverNode.
  • Distortion: set WaveShaperNode.curve to a precomputed curve; mix in parallel.
